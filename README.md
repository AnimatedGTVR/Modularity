# Modularity Fork

This is my personal fork of **Modularity**.

The purpose of this repository is to experiment with new ideas, test changes, and occasionally make improvements without affecting the main project. It also serves as my development workspace for bringing **MAKO** support and related compiler work into the Modularity ecosystem.

### Goals

* Experiment with new features and ideas.
* Develop and test the MAKO compiler.
* Prototype integrations before they're ready for the main project.
* Learn more about Modularity's internals along the way.

> **Note:** This is not the official Modularity repository. All credit for the original project goes to the Modularity developers.
